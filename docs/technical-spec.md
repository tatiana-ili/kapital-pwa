# Полное техническое задание проекта «Капитал»

Создай персональное веб-приложение для контроля личных финансов пользователя, который пользуется четырьмя российскими банками:

- Т-Банк
- Сбер
- Яндекс Банк
- Ozon Банк

Основная задача приложения — объединять банковские операции из разных источников в одну базу, автоматически категоризировать их и показывать понятную аналитику расходов, доходов, накоплений и общего капитала.

## 1. Формат приложения

Создай mobile-first PWA, удобную для использования на Android.

Технологический стек:

- Next.js
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- возможность установки PWA на главный экран Android

Приложение должно корректно работать как на телефоне, так и на компьютере.

## 2. Безопасность

На первом этапе приложение НЕ должно подключаться к банковским аккаунтам напрямую.

Не запрашивать:

- логины банков
- пароли
- SMS-коды
- данные для входа в банковские приложения

Все банковские данные пользователь импортирует самостоятельно через файлы выписок.

Исходный код не должен содержать секреты.

Все API keys должны храниться через environment variables.

Использовать авторизацию Supabase.

Приложение предназначено первоначально для одного пользователя.

## 3. Импорт банковских операций

Добавить страницу:

`/import`

Пользователь может загрузить:

- CSV
- XLSX
- при возможности PDF

Поддержать выписки из:

- Т-Банка
- Сбера
- Яндекс Банка
- Ozon Банка

Архитектура импорта должна быть модульной.

Создать отдельные parser-модули:

- tbankParser
- sberParser
- yandexParser
- ozonParser

Каждый parser преобразует данные банка в единый формат.

Если структура файла неизвестна, приложение должно:

1. определить колонки;
2. показать предварительный просмотр;
3. предложить пользователю сопоставить колонки;
4. сохранить это сопоставление для следующих импортов.

Перед записью показать экран предпросмотра:

- количество операций
- период
- банк
- общая сумма доходов
- общая сумма расходов
- возможные дубликаты

## 5. Защита от дублей

Например, hash на основе:

```text

```

## 6. Собственные переводы

Это критически важная функция.

Переводы между счетами пользователя не должны отображаться одновременно как расход и доход.

Например:

```text
Т-Банк → Сбер
-50 000 ₽

Сбер
+50 000 ₽
```

Система должна попытаться автоматически определить, что это внутренний перевод.

Использовать:

- одинаковую или близкую сумму
- близкую дату
- разные счета пользователя
- ключевые слова "перевод", "между счетами" и аналогичные

Связать две операции через transfer_group_id.

Добавить возможность вручную:

"Отметить как перевод между своими счетами".
